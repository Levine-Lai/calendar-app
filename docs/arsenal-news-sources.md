# 阿森纳新闻源方案

## 当前已接入

- `Arsenal.com` 官方文章 Sitemap：主数据源。更新器读取最近文章地址，再从公开文章结构化数据中提取标题、作者、发布时间、官方图片和简短双语摘要；完整文章通过“打开原文”进入官网。
- `The Guardian /football/arsenal/rss`：第二数据源。读取带作者署名的公开 RSS 条目，同样只保留短摘要、图片和原文链接。
- GitHub Actions 每小时在第 12、42 分钟并行刷新两个来源。任一来源失败时继续使用该来源上次成功缓存，两个来源都失败时不覆盖现有 JSON。
- App 读取顺序为 GitHub Raw、jsDelivr CDN、本地 APK 内置 JSON；网络较慢时会在取得首个可用缓存后快速显示，不再等待全部远端请求超时。

## 暂不采用

- `Arseblog` / `Arseblog News`：网站提供 Feed，但当前自动请求出现 403，稳定性不足；在确认长期可访问或获得明确许可前不加入自动更新。
- `The Athletic` 等付费来源：不抓取正文，也不绕过登录或付费墙。

## 数据原则

1. 只接受 HTTPS，文章域名和图片域名都使用白名单。
2. App 内保存短摘要，不复制第三方完整文章；始终显示来源和作者，并保留原文入口。
3. 单个源失败时保留本地缓存，不能让整个新闻页变空。
4. 调整来源前，重新验证 robots、服务条款、RSS 可用性和请求频率。
